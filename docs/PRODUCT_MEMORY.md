# OmniClaw Product Memory

## What is now persisted

- conversation history
- notes
- research records
- generated artifacts

## Why this matters

Better assistant products do more than answer one prompt at a time. They remember:

- what they found
- what they created
- what the user is trying to build

OmniClaw now has the beginnings of that product memory layer.

## Current behavior

- web research results are saved to memory
- file writes create artifact records
- the UI exposes recent research and recent artifacts

## Next memory upgrades

1. Artifact previews
2. Research source ranking
3. Citation snippets
4. Cross-link tasks with artifacts and research
5. Search across memory
