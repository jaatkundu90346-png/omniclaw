# OmniClaw Product Vision

## Mission

Build a better OpenClaw-style product by focusing on what users actually need:

- clarity
- speed
- control
- reliability
- low operational burden

## Product principles

### 1. User-needs first

OmniClaw should help users:

- remember things
- plan work
- execute safe local tasks
- connect to models and tools
- inspect what the agent is doing

### 2. Lightweight by default

Heavy platforms often become hard to run, debug, and trust. OmniClaw should keep:

- minimal dependencies
- modular features
- profile-based runtime behavior
- optional advanced components

### 3. Explainable agent behavior

Every important response should have visible:

- intent
- plan
- tool usage
- memory influence
- runtime profile

### 4. Local-first, not local-only

The control plane should run locally, but the model backend should remain swappable:

- mock
- OpenAI-compatible APIs
- future Ollama support
- future local model runners

### 5. Safe power

OmniClaw should earn trust by making execution visible and permissions explicit before adding more powerful automation.
