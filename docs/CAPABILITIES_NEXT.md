# OmniClaw Capability Expansion

## Newly added capabilities

- Protected file writing inside allowlisted workspace roots
- Lightweight web research through public web sources
- Task runner that turns saved tasks into executable workflow summaries

## Why these matter

These features move OmniClaw closer to a real product:

- it can create artifacts, not just talk
- it can gather outside context, not just local context
- it can convert intentions into runnable work units

## Guardrails

- file writes are limited to configured writable roots
- shell commands are still planned, not blindly executed
- research is intentionally lightweight and public-source based

## Best next upgrades

1. Real shell approval and execution UI
2. File diff and patch tools
3. Source ranking and citation memory
4. Browser automation sessions
5. Background scheduler and recurring jobs
