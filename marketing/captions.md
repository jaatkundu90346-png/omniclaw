# Ad captions — copy/paste for the social post

The ad itself is English-first (the product's own rule: start in English, mirror
the user). Captions below are English; add a Hindi/Hinglish line at the end if
your audience writes that way.

What the video actually shows (all of it is a real run, captured from the real
app on the real machine):

1. the hook — an agent that does not live in someone else's cloud
2. the toolbox — 200+ tools, running locally
3. the task — "Write a one-page landing page for a coffee shop…"
4. the work — the agent's own step list: thinking, `write_file`, `edit`,
   `load_toolset`, `browser_open`, `browser_screenshot`, `browser_evaluate`
5. the build — the landing page the agent wrote, opened in the browser
6. the report — the agent's own summary of what it made and how it checked it
7. the CTA

## Notes

- The videos are in `dist/social/` (git-ignored build output; re-render with
  `npm run video:render` / `npm run video:render:square`).
- Formats: `omniclaw-ad-vertical.mp4` (1080×1920 — Reels / Shorts / TikTok /
  Stories) and `omniclaw-ad-square.mp4` (1080×1080 — feed posts).
- Every frame is a real capture of the product on the machine it runs on. No
  mock-ups, no stock UI.
- The voiceover is synthesised locally (Windows SAPI) and the music bed is
  generated by `scripts/make-music.mjs` — no licensed audio, nothing to expire.
