## Notes

- The videos are in `dist/social/` (git-ignored build output; re-render with
  `npm run video:render` / `npm run video:render:square`).
- Formats: `omniclaw-ad-vertical-1080x1920.mp4` (Reels / Shorts / TikTok /
  Stories) and `omniclaw-ad-square-1080x1080.mp4` (feed posts).
- A landscape 1920×1080 cut for YouTube / LinkedIn can be rendered from the same
  composition (ask for it).
