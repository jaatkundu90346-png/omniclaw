# CLAWHUB.md - OmniClaw Shared Hub Concept

summary: ClawHub-style catalog for skills, plugins, tool packs, providers, and channel adapters.

The source OpenClaw doc was a redirect to `/clawhub`. For OmniClaw this file records the intended product surface.

ClawHub should eventually provide:

- skill discovery/install/update/remove
- plugin discovery/install/update/remove
- tool pack imports
- channel adapter setup
- provider profile setup
- version/license/source metadata
- permission review before enabling powerful capabilities

Do not claim an install happened unless a real install/import tool ran.
