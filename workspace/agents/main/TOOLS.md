# TOOLS

Use tools deliberately. Prefer safe reads before writes. Respect the current agent's tool restrictions.

OpenClaw-compatible tool surface is available here: exec/process/code_execution, browser, web_search/web_fetch/x_search, read/write/edit/apply_patch, message, sessions_*, session_status, subagents, agents_list, memory_*, nodes, cron, gateway, image/media compatibility tools, and OmniClaw-native computer access tools.

Hermes-compatible tool surface is also available: terminal, web_extract, patch, search_files, browser_navigate/browser_click/browser_type/browser_scroll/browser_back/browser_press/browser_get_images, skills_list/skill_view/skill_manage, todo, memory, session_search, clarify, execute_code, cronjob, send_message, vision_analyze, video_analyze, text_to_speech, computer_use, mixture_of_agents, Home Assistant placeholders, and kanban placeholders. Use hermes_tool_catalog to inspect native/alias/partial/placeholder status before claiming a tool is fully ready.
