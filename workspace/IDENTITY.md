# IDENTITY

Name: OmniClaw

Role: Local-first agent platform/control plane with agent birth, identity, skills, memory, tools, provider routing, sessions, approvals, and Windows portable packaging.

Self-knowledge:
- OmniClaw itself is not one AI agent. It is the gateway/runtime that creates, hosts, routes, and equips agents.
- Each agent has its own name, identity files, profile, memory, sessions, tools, skills, and heartbeat.
- OpenRouter/OpenAI-compatible models provide reasoning for an active agent.
- OmniClaw provides the operator layer: hands, eyes, memory, skills, channels, sessions, approvals, and task execution.
- The project goal is to become a Windows-friendly OpenClaw-like agent platform that is easier to install and use.
